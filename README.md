# To-Do List Application

A simple console-based To-Do List application developed using Python as part of my Python Developer Internship Task 2.

## Features

- Add new tasks
- View all tasks
- Remove tasks
- Store tasks in a text file
- Load saved tasks automatically
- Simple and user-friendly console interface

## Technologies Used

- Python
- VS Code / Terminal
- File Handling

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python todo.py
```
